Projects

LegalFlow: Legal Case-Management SaaS with an AI Assistant

Team project

A working platform law firms use to run their cases, where each firm gets its own database schema. I owned several feature areas end to end.

  • Built LOIS, an AI assistant with 20+ tools, each limited to the right firm and user role. It can carry out several steps in one request and drafts letters from case data and templates.
  • Gave it the ability to read case files using Gemini embeddings, pgvector and an OCR pipeline. It searches and summarizes documents and extracts deadlines, parties and key facts, each with a confidence score and a link back to the source.
  • Built a unified inbox for text, email and fax (Twilio, Resend, Telnyx) with per-firm routing and signature checks on every webhook.
  • Wrote Playwright end-to-end tests and database migrations that are safe to re-run.
